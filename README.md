# Бизнес-инсайты — публичная архитектура

Статический сайт с архитектурой решения для кейса Альфа-Банка «Новостная аналитика для принятия бизнес-решений».

Сайт не содержит клиентских данных, ключей, учётных данных или работающей интеграции с системами банка.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер из корня репозитория.

## Публикация

Vercel определяет проект как статический сайт. Для публикации из CLI:

```bash
npx vercel --prod
```
