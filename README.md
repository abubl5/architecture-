# Бизнес-инсайты Альфа-Банка — Structurizr

Этот репозиторий публикует интерактивный статический экспорт Structurizr. Он содержит те же C4-диаграммы и динамические сценарии, которые команда просматривает локально в Structurizr Lite.

## Что опубликовано

- девять диаграмм: контекст, контейнеры, формирование контекста компании, понимание события, подготовка бизнес-инсайта, пользовательский путь, уточняющий вопрос и два компонентных представления;
- навигация по диаграммам, масштабирование, подсказки, легенда и анимация динамических сценариев;
- только описание архитектуры и её элементы — без CSV, PDF, ключей, пользовательских данных или реализованного бэкенда.

Каталог `public/` содержит статический экспорт Structurizr и развёртывается Vercel как обычный статический сайт. В нём находится скомпилированная модель `workspace.js` и все необходимые локальные JavaScript-, CSS- и графические файлы просмотрщика.

## Защита доступа паролем

Перед публикацией в Vercel добавьте две переменные окружения для **Production** и **Preview**:

- `ARCHITECTURE_PASSWORD` — пароль, который вы сообщите коллегам;
- `ARCHITECTURE_SESSION_SECRET` — случайная секретная строка длиной не менее 32 символов.

Пароль не попадает в репозиторий. Vercel сначала проверяет его в серверной функции, а затем выдаёт браузеру подписанную cookie на 14 дней. Маршрутизатор Vercel проверяет эту cookie до выдачи любого файла из `public/`, включая модель диаграмм и скрипты Structurizr.
